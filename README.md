# My Personal Site

This is my personal website. I made it to showcase my projects and share things about me. 

I have used a space theme for this site with picture of moon's surface in background and stars which react to mouse hover with the same. I have used three different kinds of animations for switching between different pages. I decided to used a TV with my name for the landing and gave it a 3D effect. I had made many changes in this site previously too and this is the final design that I landed upon after trying a lots of others.

## Getting Started
You can install and run it locally from the following steps : 

### Installing

Clone the repository:

```bash
git clone https://github.com/shreyanshpurohit/My-personal-website.git
```

Move into the project folder:

```bash
cd My-personal-website
```

### Running the website

Open `index.html` in your browser.
